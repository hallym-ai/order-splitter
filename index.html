발주 파일 분리기

마스터 파일을 품목별 발주처 파일로 분리하는 시스템입니다.
직전 발송본과 사업자등록번호로 대조해 변경 셀만 표시하며, 변경 없는 발주처는 미생성합니다.

실행 브라우저 내 처리 · 외부 전송 없음 설치 불필요 대조 키 사업자등록번호

01파일 선택

  • 현재 마스터 파일만 업로드 시, 변경 사항 표기 없이 업체별 파일만 생성합니다.
  • 직전 발송 마스터 파일도 업로드 시, 변경 사항 표기하여 업체별 파일 생성합니다.

적용 규칙

파일명
마스터 파일명 + _발주처. 마스터가 2027 서울커피엑스포 마스터 파일.xlsx면 2027 서울커피엑스포 마스터 파일_전기.xlsx.
대조 키
사업자등록번호. 번호 일치 행끼리 비교. 번호 누락 또는 중복 시 생성 중단 후 해당 업체 표시.
공통 열
마스터 파일 A~N열 형식 그대로(연번 · 업체 특이사항 · KCA 회원사 · 업체명 · 배치 · 최종 부스번호 · 담당자 정보) + 사업자등록번호. 전 발주처 파일 공통 포함.
분리 기준
마스터 파일의 품목 열. 전기 · 급배수 · 압축공기 · LAN · 부스(독립 · 조립 · 프리미엄), 품목 1개 = 파일 1개. 전기는 주간 · 24시간 × 단상 · 삼상 6열 포함. 품목 변경 시 업체매핑 시트로 지정.
포함 행
해당 품목 수량 1 이상. 직전 1 이상 → 현재 0인 취소 건 포함.
변경 표시
빨간 글씨 + 노란 바탕. 수량 · 부스번호 변경, 신규 참가업체 대상.
취소 처리
행 유지, 수량 0. 비고에 직전 수량 기재.
건너뜀
해당 품목 변경 0건 시 파일 미생성.
행 삭제 감지
직전 수량 있음 + 현재 행 없음 → 취소 여부 확인 경고 행 삽입.
